# Sidebar

The left sidebar: New session, History, workspace blocks with projects and their sessions (state glyph, name, diff stat or status), and the settings footer. Wrap it in `MoonletPreview` for the demo workspaces.

```tsx
<MoonletPreview>
  <div style={{ width: 280, height: 640 }}><Sidebar /></div>
</MoonletPreview>
```
